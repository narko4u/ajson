# Contributing

Thank you for your interest in contributing!

## Scope

This repository is part of the Empire Labs open-source stack (ACI, AIP, AJSON, and related tooling). It contains only the open-source components described in the README. Proprietary platform components are not part of this repository.

## Development setup

```bash
git clone https://github.com/narko4u/ajson.git
cd ajson
```

Follow the README instructions for building and testing.

## Making changes

1. Fork the repository (or create a branch if you have write access)
2. Make your changes with clear commit messages
3. Add or update tests where applicable
4. Ensure CI passes
5. Open a pull request

## Commit conventions

- Use clear, descriptive commit messages
- Sign your commits with `Signed-off-by` (DCO)
- Keep pull requests focused on a single change

## Code of conduct

Be respectful and constructive. Harassment or abusive behaviour is not tolerated.

## Questions

Open a GitHub issue for questions, or email [contact@empirelabs.com.au](mailto:contact@empirelabs.com.au).
